# 05 字符绘图、UI 与对话框

## 本章目标

用 `TerminalCanvas` 做一个透明 HUD 和一个可切换的对话框，理解字符、前景色、背景色与标志位如何共同构成一个格子。

## TerminalStyle

```csharp
private static readonly TerminalStyle WhiteOnBlack = new TerminalStyle(
    new Color32(235, 245, 240, 255),
    new Color32(0, 0, 0, 255));

private static readonly TerminalStyle Warning = new TerminalStyle(
    new Color32(255, 196, 64, 255),
    new Color32(0, 0, 0, 0),
    TerminalCellFlags.TransparentBackground | TerminalCellFlags.Blink);
```

一个格子包含：Glyph、Foreground、Background、Flags 和 Effects。背景 Alpha 为 0 但没有 `TransparentBackground` 标志，不应假定一定按透明窗口处理；直接使用 `TerminalStyle.Transparent` 最安全。

## Canvas 常用操作

```csharp
TerminalCanvas c = window.Canvas;
c.Clear(WhiteOnBlack);
c.Put(4, 3, '@', Warning);
c.Write(2, 5, "HP 12/20", WhiteOnBlack);
c.Fill(new RectInt(1, 8, 20, 2), '.', WhiteOnBlack);
c.DrawBox(new RectInt(0, 0, c.Width, c.Height), WhiteOnBlack);
```

所有操作都会裁剪到 Canvas 范围，不会写坏相邻窗口。`Put` 超界时返回 `false`。

## 对话框脚本片段

在上一章模块中增加一个更高 Layer 的窗口：

```csharp
private TerminalWindow _dialog;

private static readonly TerminalStyle DialogFrame = new TerminalStyle(
    new Color32(255, 235, 180, 255),
    new Color32(0, 0, 0, 255));

private void OpenDialog(string speaker, string text)
{
    if (_dialog == null)
    {
        _dialog = _terminal.OpenWindow(
            "dialog",
            new Rect(0.08f, 0.68f, 0.84f, 0.25f),
            new Vector2Int(84, 14),
            layer: 50);
    }

    _dialog.Visible = true;
    TerminalCanvas c = _dialog.Canvas;
    c.Clear(DialogFrame);
    c.DrawBox(new RectInt(0, 0, c.Width, c.Height), DialogFrame);
    c.Write(3, 1, speaker.ToUpperInvariant(), DialogFrame);
    c.Write(3, 3, text, DialogFrame, maxWidth: c.Width - 6, wrap: true);
    c.Write(3, c.Height - 2, "[SPACE] CONTINUE", DialogFrame);
}
```

如果对话框只想显示框和字，让下方世界透出来，应清屏为透明样式，并保证边框样式背景也透明：

```csharp
c.Clear(TerminalStyle.Transparent);
c.DrawBox(area, TerminalStyle.Transparent);
```

## 自动换行的真实规则

```csharp
Vector2Int end = c.Write(
    3,
    3,
    longText,
    DialogFrame,
    maxWidth: 70,
    wrap: true);
```

- 起点是 `(3,3)`；
- `maxWidth` 是从起点开始每行允许的宽度；
- `0` 表示使用 Canvas 右侧剩余宽度；
- `\n` 强制换行；
- `\t` 按 4 格制表；
- 返回值是写完后的光标位置。

## SubCanvas：限制组件绘制区域

```csharp
TerminalCanvas inventory = c.CreateSubCanvas(
    new RectInt(2, 8, 30, 10));

inventory.Clear(TerminalStyle.Transparent);
inventory.DrawBox(
    new RectInt(0, 0, inventory.Width, inventory.Height),
    TerminalStyle.Transparent);
inventory.Write(2, 2, "KEY x1", TerminalStyle.Transparent);
```

SubCanvas 的 `(0,0)` 对应父 Canvas 的 `(2,8)`，并且自动裁剪。它适合让多个 UI 绘制器共用一个窗口而互不越界。

## 直接访问 Surface 的边界

普通 UI 优先用 Canvas。只有以下情况再用 Surface：

- 大量程序生成格子；
- 复制/比较整块字符数据；
- 实现自己的地图渲染器；
- 精确管理 dirty 区域。

直接写 RawCells 时必须正确调用批处理和标脏，否则 GPU 端可能不知道内容已经变化。

## 实践任务

做一个 HUD：

- 左上角显示 HP；
- 右上角显示三个闪烁信号点；
- 底部对话框可显示/隐藏；
- 世界窗口仍可透过 HUD 空白区域；
- 把库存区域做成 SubCanvas。

## 误区陷阱

“背景颜色写成黑色，因为黑色看起来像透明。”错误。黑色仍是不透明颜色；透明是 Alpha/Flag 与合成规则。
