# 第一部分常见故障排查

## 菜单不存在或脚本不能加载

先看 Console 的第一条编译错误。`The associated script can not be loaded` 通常是整个程序集编译失败、文件名与 MonoBehaviour 类名不一致，或脚本缺少 `using AsciiTerminal;`，不一定是 Inspector 引用本身损坏。

## 画面完全为空

依次检查：

1. Camera、`TerminalDisplay`、`TerminalModuleHost` 是否启用；
2. 模块是否被 Host 收集；
3. `ModuleId` 是否重复；
4. `OnTerminalOpen` 是否真的执行；
5. Window 的 Bounds、Surface 是否为正数；
6. Window 的 `Visible` 是否为 true；
7. 字体/Shader/Compute Shader 是否丢失。

## UI 变成黑色矩形

UI 空白格使用了不透明背景。把叠加窗口清成 `TerminalStyle.Transparent`，并检查自定义样式的背景 Alpha 与 `TransparentBackground` 标志。

## 窗口之间出现缝隙

让相邻窗口共享同一个 split 值，并统一通过归一化 Rect 计算。改变 Terminal 分辨率后重新执行布局函数。

## 下方出现横向黑区

先区分四种原因：Camera Viewport/Aspect、Window Bounds 没铺满、Surface 宽高比被保持、某个高 Layer 黑色窗口遮挡。逐个隐藏窗口并暂时关闭最终 Post FX，找出黑区属于哪一层后再修改。

## 输入无效

检查 Host 的旧输入轮询是否启用；使用新 Input System 时，需要在 Action 回调中调用
`moduleHost.SendInput(...)`。还要检查前面的模块是否已返回 true 消费该事件。
