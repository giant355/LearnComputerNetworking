## 使用方式

每一章都按同一节奏推进，但只保留完成任务真正需要的解释：

```text
先观察现象 → 预测结果 → 实际接线/编码 → 运行验证 → 用自己的话解释
```

不要一次复制整章代码后只确认“能跑”。每完成一个小阶段就进入 Play Mode，验证教程列出的可观察结果。看不懂的代码可以先照着使用，再随时提问。

## 默认前提

- Unity：`2022.3.42f1c1`；
- 目标：Windows 桌面纯单机；
- 渲染管线：初学阶段优先 Built-in，之后再按需切换 URP/HDRP；
- 编程：会创建 C# 脚本，理解字段、方法、类、数组和 Inspector；
- 不包含：XR/VR、网络同步、多人存档。

如果 C# 或 Unity 生命周期还不熟，可按需查看 [[补充课程/CSharp与Unity最小补课]]。
