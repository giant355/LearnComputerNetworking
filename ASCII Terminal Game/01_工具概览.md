# 01 工具概览

## 它是什么

ASCII Terminal 是 Unity 2022.3 中的一套“假终端”显示与游戏框架。整个游戏画面可以被理解为一个可调字符分辨率的舞台，例如 `160×90` 或 `400×200`。开发者在舞台上自由创建窗口，再把字符 UI、二维地图、三维 Camera、图片、视频和演出放进去。

它不是 Unity UI 的皮肤，也不是单纯的全屏滤镜。它同时提供：

- 字符格数据与安全绘图；
- 任意数量、位置、占比和层级的窗口；
- Camera/Texture/视频到 ASCII 的转换；
- 字符重组和手绘关键帧；
- Sequence 与 Timeline 演出；
- 全屏及单窗口 CRT 效果；
- 统一单机存档与项目扩展接口。

## 开发者通常接触的四层

```text
游戏模块：地图、状态、输入和规则
    ↓
TerminalWindow + TerminalCanvas：窗口和字符绘制
    ↓
Raster / Effects / Sequence / Timeline：混合媒介和演出
    ↓
TerminalDisplay：字体、GPU 合成和最终 Camera 输出
```

初学时只需理解前两层。后两层在第二、第三批教程再使用。

## 第一批会做到什么

三天内完成一个小型二维 ASCII 房间：

- 玩家可移动；
- 有墙、门、物品和交互；
- 有透明状态栏、日志与对话框；
- 窗口位置和占比可变化；
- 终端分辨率改变后仍能正常显示。

## 暂时不用理解的内部细节

这些可以先视为黑箱：Compute Shader、GraphicsBuffer、字体图集采样、SRP 注入、临时 RenderTexture 和后处理 Material。开发游戏时优先使用公开接口，不直接修改这些内部实现。

## 后续两批

- 第二批：Camera/图片/视频 ASCII 化、字符重组、手绘关键帧。
- 第三批：Sequence、Timeline、滤镜、多输出、扩展接口和统一存档。

项目目标是桌面纯单机，不包含 XR/VR 和网络同步。
